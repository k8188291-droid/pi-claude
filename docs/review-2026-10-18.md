# pi-claude Code Review（2026-10-18）

## 怎麼做的

1. **錄製真實 session：** 用 `parity/record.ts` 讓 Claude Code（Agent SDK 0.3.302 附帶的 2.1.302）review 這個 repo，模型是 `gpt-6.1-sol`（透過 Anthropic 相容的代理）。共錄了兩次。第二次錄下的 session 收在 `parity/recordings/review-pi-claude.json`：47 個主回合、4 個 subagent、243 次工具呼叫。
2. **逐項驗證：** 把第一次 review 的 28 項發現各寫成探測情境，讓 Claude Code 和 pi-claude 各跑一次，依結果分類。工具碰不到的部分（pi 內部生命週期、parity 框架本身）則直接呼叫模組，或比對 Claude Code 內嵌的原始碼。兩次 review 的主要發現一致。
3. **重播比對：** 把錄下的 243 次工具呼叫在兩邊重播。修正下面兩個問題後，**225/243 步完全一致，沒有遺漏的步驟**。其餘 18 步都是環境雜訊：process id、時間戳、測試耗時、模型自己寫的腳本裡的隨機名稱、Grep 多檔順序，以及背景通知附在哪一步。

### 錄製與重播找到、已修正的問題

- **pi-claude 缺少 `claude` agent 類型。** Claude Code 的 SDK 版本內建一個 catch-all 類型 `claude`，真實模型在這次 session 裡 4 個 subagent 全都用它。手寫情境沒有涵蓋到。已補上。
- **parity 框架：**
  - pi runner 會在背景 subagent 還沒做完時就關掉 session；
  - 重播時的 id 對應會把 `sleep 1` 換成 `sleep 2`；
  - 檔案內容含 `<system-reminder>` 字樣時，會被當成雜訊刪掉；
  - 相似 prompt 的 subagent 路由會互相衝突。

  以上都已修正。
